Onboarding checklist (manual, one-time per dealer)

1. Supabase Dashboard → Authentication → Add user: the login email above, password = the passcode, auto-confirm ON.
2. SQL editor → insert the profile row: insert into public.profiles (id, email, role, dealer_id, status) values ('<auth-user-uuid>', '<login email>', 'owner', '<dealer-id>', 'active');
3. Create the dealer here (form above). 4. Hand the dealer their passcode — they sign in with it on the landing page.
Passcode reset: set a new one here, then update the auth user's password to the same value in the Dashboard.
